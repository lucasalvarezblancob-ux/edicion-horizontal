# Edición de reels

Esta carpeta es **solo para editar reels verticales** (9:16). Para cualquier petición de edición, guion, voz en
off, subtítulos, gancho, transiciones, descripción o "que aprendas" de una corrección: **carga primero la skill
`edicion-reels`** (`.claude/skills/edicion-reels/SKILL.md`).

| Carpeta | Qué hay |
|---|---|
| `personal/` | **Lo tuyo**: `perfil.md` (nombre, cuentas, coletillas…) y `preferencias.md` (tus reglas; mandan sobre las estándar). |
| `bruto/` | Bandeja de entrada: vídeos en bruto pendientes de editar. |
| `bruto terminado/` | Brutos ya editados que no son clips de entreno. |
| `refs/<tipo>/` | Tus referencias locales (las estándar vienen con la skill). |
| `recursos/` | Tu material reutilizable + `INDICE.md`. |
| `out/` | Vídeos terminados + `REGISTRO.md`. |
| `estudio/` | Proyecto Remotion. Color y fuentes en `src/comun/marca.ts`. |
| `herramientas/` | Scripts (análisis, voz, música, transcripción) + `.venv` + modelo Whisper. |

La skill es de solo lectura: lo que cambies o aprendas se queda en esta carpeta. No crees carpetas nuevas en la
raíz sin preguntar.
